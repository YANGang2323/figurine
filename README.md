# figurine

미디어프로젝트 공유용 Unity 프로젝트입니다.

- Unity 버전: 6000.3.15f1
- 프로젝트 열기: Unity Hub에서 이 저장소 폴더를 추가합니다.
- 개발 이력: Unity Version Control의 변경 기록을 Git 커밋으로 이전했습니다. 각 커밋 메시지의 `Changeset:` 뒤에 원래 변경 번호가 표시됩니다.
- 이전 범위: 최초 개발 기록부터 변경 번호 211까지, 개발 커밋 210개입니다. 작성자, 작성 시각과 변경 메시지를 보존했습니다.

[전체 커밋 기록 보기](https://github.com/YANGang2323/figurine/commits/main/)

이 저장소에는 Unity Version Control에 체크인된 기록이 포함됩니다. 체크인하지 않은 로컬 변경은 포함되지 않습니다.
